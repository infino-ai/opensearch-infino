# Security Policy

## Reporting a vulnerability

**Please do not open a public issue for security vulnerabilities.**

Report security issues privately through GitHub's private vulnerability
reporting: open the **Security** tab on
<https://github.com/infino-ai/opensearch-infino> and choose **Report a
vulnerability**.

Please include enough detail to reproduce the issue: the plugin commit, the
OpenSearch release, the mode (default or proxy) and storage in use, the steps,
and the impact. We aim to acknowledge reports within a few business days and
will keep you updated on remediation. Coordinated disclosure is appreciated,
and we will credit reporters who wish to be named.

A problem in the `infino` engine itself, rather than in the plugin or its
bridge, can be reported the same way on
<https://github.com/infino-ai/infino>.

## Supported versions

The plugin is experimental and under active development. Security fixes are
made on the default branch, for the OpenSearch releases it builds against;
there are no long-term support branches.
