# Stock YAML REST tests the core suites skip (coreYamlRestTest,
# coreYamlRestTestProxy, coreYamlRestTestLucene).
#
# A run should report 0 failures: every test that is known not to pass is
# skipped here, with its reason, so any failure is a regression.
#
# One entry per line:
#
#   <pattern>  # [<tag>] <reason> (<issue URL>, when there is one)
#
# The pattern is relative to rest-api-spec/test, as the YAML runner's
# tests.rest.denylist takes it:
#   search/10_source_filtering/*                   every test in a file
#   search/10_source_filtering/Source filtering    one test, by its name
# Write test names as they are; the build escapes the characters the runner
# would read as a regular expression or a list separator. The runner matches
# a pattern against the end of the test's path, so get/40_routing/Routing
# also skips mget/40_routing/Routing.
#
# The tag says which tasks skip the test:
#   [gap]        the test needs a feature Infino does not have yet, in the engine
#                or the plugin; remove the entry when the feature lands
#   [bug]        any other failure: a wrong answer, a 500, or a refusal of what
#                an existing feature should handle; remove the entry with the fix
#   [by-design]  Infino answers better than stock on purpose, and the test
#                asserts stock's weaker behaviour; the entry stays
#   [cluster]    fails on the same cluster without the plugin too
# A check stock makes that the plugin skips, so the plugin answers or accepts
# a request stock rejects, is a [gap]. A feature the plugin silently ignores
# while answering is a [bug] until the plugin refuses the request.
# gap, by-design and bug may be narrowed to one mode: [gap:proxy], [bug:default].
# Without a mode they apply to both. coreYamlRestTestLucene skips only
# [cluster] entries.
#
# -Dinfino.core.skip chooses how much is skipped:
#   all    (default) every entry for the task's mode
#   gaps   [gap], [by-design] and [cluster] only, so the known bugs run and fail
#   none   nothing, to find entries whose tests pass now
# scripts/core-denylist.py reads a run's results and prints the failures no
# entry covers, and the entries whose tests all passed.
#
# Blank lines and lines starting with # are ignored. A line without a tag and
# a reason fails the build.
